## Running the Agents

1. **Open a terminal** and navigate to this project folder:

    ```sh
    cd agents/adk_agents
    ```

2. **Start the agent development kit (ADK) web interface**:

    ```sh
    adk web
    ```

3. **Test your agents** using the web interface that opens.

> Make sure you have installed all required dependencies (e.g., via `pip install -r requirements.txt`).
